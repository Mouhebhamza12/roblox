# Roblox

An empty Roblox game project managed with [Rojo](https://rojo.space/).

## Getting started

1. Install Rojo and the Rojo plugin for Roblox Studio.
2. From this folder, run `rojo serve` and connect to it from the plugin in Studio.
3. Add game content under `src/`; the folders map to their matching Roblox services.

To build a place file without Studio, run `rojo build -o build.rbxlx`.
